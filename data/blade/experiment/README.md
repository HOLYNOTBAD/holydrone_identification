# Blade 原始实验

每个子目录代表一组独立来源的静态台架实验，包含人工转录的 `static_thrust.csv` 和记录来源的 `metadata.json`。CSV 保留原表单位；空值表示未知，不能按零处理。修改或补充原始记录后，运行 `python3 scripts/blade/blade_catalog.py` 重建数据集。

`throttle_percent` 对应截图中的“动力输出”百分数；厂家没有此列，不能反推。厂家最大推力行的 RPM 标为 Max，转录时留空。未测量的功率、效率不补算成原始测量值。暑假截图原文件目前未在仓库保存，以上表格及元数据记录其来源。两组硬件是否一致尚未确认，分别拟合，不合并为同一标定实验。

这两组轻量人工转录表和元数据纳入 Git，以便重建数据集。

新详测会话使用 `bench_<时间>/` 目录，由 [blade_excite.py](../../scripts/blade/blade_excite.py) 创建；除原表和元数据外还保存配置、遥测、事件与完成状态。操作步骤见 [blade 使用说明](../../scripts/blade/README.md#工作区间详测终端输入推力)。
