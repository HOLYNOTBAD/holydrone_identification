# ESC / 电机拟合

打开 `index.html` 离线查看，按实验及模型类型切换。

```bash
conda run --no-capture-output -n holydrone_autotune python scripts/escmotor/escmotor_fit.py
```

输入为现有 `escmotor_dataset`，不连接飞控、不修改原始数据，也不需要重新导入 ULog。每个实验和联合数据分别输出，目标电压不同则分组，不跨电压合并。

稳态映射使用各正式有效脉冲的末段转速，拟合 n=a u²+b u+c；每脉冲等权，只有测量区间内有效，不强制通过零点。这是实测供电条件下的经验曲线，没有消除压降。

启动模型复用 `escmotor_identification.py` 的带延迟一阶响应，以训练脉冲末段均值固定稳态转速，稳态多项式不参与动态拟合。每工况有多个脉冲时最后一个留出验证，单脉冲只显示样本内误差。原始停转前后样本可见，但仅保持阶段参与启动拟合。初始化使用激励前最后一个转速样本。

优化沿用 soft L1 损失及原参数边界；参数触边、采样不足、验证误差偏大分别提示。启动时间常数不等同于旋转工作点附近的时间常数，延迟包含输出与遥测影响。联合会话的硬件型号仍需核对。

统一模型先只使用训练脉冲的末段转速拟合 f(u)，再用训练保持段拟合共同 τ 和延迟；验证脉冲既不进入 f(u)，也不进入动态参数估计。统一模型的多项式因此可能与“稳态油门—转速”面板的全数据拟合略有不同。动态目标采用原始 RPM 残差的 soft L1 损失，每个采样点等权，尺度为训练稳态转速中位数的 2%。与逐档模型的比较在相同脉冲和时间点上进行，差异同时包含稳态映射近似与共享动态参数的影响。只验证有重复的油门档位，不能将低油门验证推广为全区间独立验证。模型仅用于已测范围的启动响应，不用于零油门稳态或停机。统一结果另存 unified_model.json、unified_predictions.csv、unified_comparison.csv 和对比图。

每组保存 report.json、steady_points.csv、startup_parameters.csv、逐工况采样预测 CSV，以及 SVG/PNG/PDF 图。results.json 包含来源索引指纹及参与动态拟合的样本文件指纹。排除的试转和质量异常记录在 results.json 中。
